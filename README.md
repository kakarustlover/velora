# Velora — پلیر شیشه‌ای با Rust + Slint

UI دقیقاً از روی `Velora-FINAL.html` ساخته شده (اندازه‌ها از مرورگر استخراج شده)،
بک‌اند کامل Rust: اسکن موزیک، دیتابیس، پخش‌کننده با اکولایزر واقعی ۱۰ باند، نوتیفیکیشن مدیا.

## ⚠️ وضعیت صادقانه
* محیطی که کد توش نوشته شد **Rust نداشت و اینترنت هم نبود** → کد **کامپایل نشده**.
* به‌جاش: بازبینی دستی خط‌به‌خط + `scripts/lint.py` (تطبیق Slint↔Rust↔Kotlin: ۳۲ کال‌بک، ۵۹ پراپرتی،
  امضای JNI، کدهای دستور) + تست عددی فرمول‌های اکولایزر با NumPy (پایدار، بهره‌ی دقیق).
* اولین بیلد ممکنه یکی-دو خطای کوچک کامپایلر بده (به‌خصوص Slint). متن لاگ CI رو بفرست؛ هر خطا معمولاً ۱ خطه.
  خطرناک‌ترین نقاط (اگه خطا داد اول اینا): `absolute-position` (بک‌دراپ شیشه)، `rotation-angle` (دیسک)،
  `changed viewport-y =>` (اسکرول)، `Path commands` پویا (آیکون‌ها). جزئیات در `docs/REVIEW.md`.

## ساخت APK فقط با گوشی (GitHub Actions)
1. یک ریپوی خصوصی جدید در GitHub بساز.
2. محتوای همین پوشه (نه خود zip) رو آپلود کن (Add file → Upload files). پوشه‌ی `.github` هم باید باشه.
3. تب **Actions → Build Velora APK → Run workflow** (با هر push هم خودکار اجرا می‌شه).
4. بعد از ~۱۵ دقیقه، آرتیفکت **velora-apk** رو دانلود کن، `app-release.apk` رو نصب کن.
   (فونت Inter و NDK/SDK خودکار نصب می‌شن.)

## ساخت محلی (اختیاری)
```sh
sh scripts/get_fonts.sh                 # فونت Inter -> ui/fonts
cargo run                               # نسخه‌ی دسکتاپ برای تست سریع UI (~/Music)
cargo test --lib                        # تست‌های منطق
cargo ndk -t arm64-v8a -o android/app/src/main/jniLibs build --release --lib
gradle -p android assembleRelease       # APK: android/app/build/outputs/apk/release/
```

## بک‌اند چطور کار می‌کنه
| خواسته | پیاده‌سازی |
|---|---|
| فقط دسترسی موزیک در ورود | `READ_MEDIA_AUDIO` (Android 13+) / `READ_EXTERNAL_STORAGE` (≤12). مجوز نوتیف فقط یک‌بار موقع اولین پخش پرسیده می‌شه |
| اسکن فوری بعد از مجوز | ترد `velora-scan` منتظر مجوز می‌مونه و بلافاصله اسکن می‌کنه |
| فقط mp3 و فرمت‌های رایج | `mp3 m4a aac flac wav ogg oga`؛ بقیه بی‌صدا نادیده گرفته می‌شن (فایل خراب هم بی‌صدا رد می‌شه) |
| ذخیره و اسکن مجدد نشه | SQLite (`velora.db`): مسیر + اندازه + تاریخ. اجرای بعدی فقط `stat` می‌کنه و تگ فقط برای فایل جدید/تغییرکرده خونده می‌شه؛ لیست قبلی لحظه‌ی اول نشون داده می‌شه |
| فایل جدید خودکار اضافه بشه | اسکن افزایشی هر ۴۵ ثانیه + هر بار برگشت به اپ (`onResume`)؛ فایل حذف‌شده هم پاک می‌شه |
| نوتیفیکیشن مثل بقیه‌ی پلیرها | Foreground Service + `MediaSession` + `MediaStyle`: قبلی/پخش‌وقفه/بعدی، نوار seek، کاور، کنترل قفل‌صفحه، audio-focus، قطع با کشیدن هدفون |
| اکولایزر واقعی | ۱۰ باند + Bass + Treble + Preamp، فیلتر biquad روی خود صدا (`src/eq.rs`)، با ذخیره |
| پلی‌لیست | ساخت/ویرایش/حذف، پخش و شافل، ذخیره در دیتابیس |

## UI: HTML → Slint
* همه‌ی رنگ‌ها: `ui/tokens.slint` (تولید خودکار از ۲۰ ترکیب پالت×روشن/تیره‌ی HTML).
* ۱۰۰ والپیپر + نسخه‌ی بلورشده، ۲۰ دیسک شیشه‌ای: `assets/` (از خود HTML استخراج/ساخته شده).
* آیکون‌ها از SVG خود HTML تبدیل شدن: `ui/icons_data.slint`.
* اندازه‌ها و اسکرین‌شات مرجع: `docs/reference/` (مقایسه‌ی بصری با خروجی اپ).
* بازتولید: `python3 scripts/gen_assets.py Velora-FINAL.html tokens.json` و `scripts/gen_icons.py`.

### تفاوت‌های ناگزیر با HTML (بدون ادعای «۱۰۰٪»)
* **بلور پشت شیشه**: Slint `backdrop-filter` ندارد → زیر هر المان، همان والپیپرِ از قبل بلور و اشباع‌شده هم‌تراز پنجره کشیده می‌شه. روی والپیپر تقریباً هم‌ارز است؛ زیر المان‌های متحرک (ردیف‌های در حال اسکرول) بلور نمی‌شه.
* **Max (شیشه‌ی مایع SVG)**: فیلتر شکست نور قابل بازسازی نیست؛ با هایلایت و لبه‌ی روشن تقریب زده شده. Balanced = ظاهر اصلی، Optimized = بدون بک‌دراپ/سایه.
* **اسکرول دو مرحله‌ای**: به‌جای «اول لیست، بعد صفحه»، یک اسکرول واحد: هدر جمع می‌شه، بعد پنل شیشه می‌چسبه و محتوا می‌لغزه.
* حرکت آرام والپیپر (Ken Burns) و فونت: Inter از GitHub دانلود می‌شه. اگر نشد، فونت پیش‌فرض سیستم.
* ردیف «Demo sound» در شیت اکولایزر حذف شد (اپ واقعی خودش از اکولایزر رد می‌شه).

## تست پیشنهادی روی گوشی
مجوز موزیک → اسکن (لیست پر می‌شه) → بستن/بازکردن اپ (لیست فوری، بدون اسکن سنگین) → کپی یک mp3 جدید و برگشت به اپ → پخش → نوتیف → قفل‌صفحه → اکولایزر Bass → پلی‌لیست.
